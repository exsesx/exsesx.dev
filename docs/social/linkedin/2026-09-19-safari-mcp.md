## Post

Safari 27 has a built-in MCP server for AI agents. It works with Claude Code, Codex, and other MCP clients

I tried it with Codex

I asked it to open YouTube, find a creator's channel, and tell me their latest upload. It returned the title, link, upload age, and runtime

Getting connected took a few attempts. Once it worked, it felt fast. One click matched several elements, so Codex retried with a specific element identifier

Now I want to try the same workflow on my own site: change the code, open the page in Safari, and check what works

I also recorded it checking Shottr's release announcement on X against the official website, separating the available update from a bigger release that's still coming

Shout-out to Shottr, an amazing screenshot app for the Mac

I wrote about the test, the setup, and a few other Safari 27 changes, including customizable select controls and scroll anchoring
